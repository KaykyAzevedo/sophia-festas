# Sophia Festas

Protótipo visual (somente front end) do site da casa de festas **Sophia Festas**.

- `index.html` — landing page (preto, azul e metal, com borboletas)
- `agenda.html` — área da equipe para agendamentos (login de demonstração; dados salvos só no navegador)

Abra `index.html` no navegador — não precisa de build nem servidor.
